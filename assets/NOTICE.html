模型、软件许可与源代码

本站按需提供浏览器使用的公开模型和软件。下载文件的原始地址、固定版本、大小和 SHA-256 见模型与运行文件清单。下列源代码和许可同样可以免费下载。

中文翻译

中译英模型由赫尔辛基大学语言技术研究组（Helsinki-NLP / OPUS-MT）开发，按照 CC BY 4.0 授权。Xenova 将原模型转为适用于 Transformers.js 的 ONNX 格式，本站提供该版本的量化文件，保持发布时的字节。参考文献为 Jörg Tiedemann 和 Santhosh Thottingal，OPUS-MT — Building open translation services for the World（2020）。见原模型说明、转换说明及许可摘要。

英语配音

Kokoro-82M v1.0 模型来自 hexgrad，ONNX 版本由 onnx-community 发布。语音权重、英文音色向量和 Kokoro.js 自身的代码按 Apache 2.0 授权。见模型说明和Kokoro.js 的源码与构建脚本。

Kokoro 浏览器程序含有 phonemizer.js 1.2.1 的英文语音转换代码，其封装采用 Apache 2.0。其中使用的 eSpeak NG 引擎由 Jonathan Duddington 和 eSpeak NG 贡献者开发，按 GPL 第 3 版或以后版本提供。可以下载eSpeak NG 的 C 源码、词典输入及构建脚本，以及 Emscripten 运行库许可。eSpeak NG 部分文件亦附有 Apache、BSD 和 Unicode 数据条款。上游编译版本的核对范围见下方构建记录。

浏览器推理运行库

Transformers.js 由 Hugging Face 及贡献者开发，采用 Apache 2.0。可阅v2 源码并下载v3 构建源码。Hugging Face Jinja 遵守 MIT 条款（翻译版本、配音版本）。

ONNX Runtime Web 由 Microsoft Corporation 及贡献者开发。翻译组件附有 MIT 许可和第三方声明。配音组件附有 MIT 许可和第三方声明。
