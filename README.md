# 英语搭子

粘贴带昵称的微信文字，或从设备选择微信导出的 ZIP 聊天记录，在浏览器中得到分角色英语朗读和逐句滚动的双语字幕。可点一句重听、调速、隐藏原文，也可将用 Kokoro 配音的听力卡保存成可离线播放的 HTML 文件。

打开网站可直接听六句虚构示例。首次制作默认选择「在线快读」，译文可用设备已有英语声音直接朗读，也可另选自然双人配音。两种读法都不下载模型。纯英文跳过在线翻译。含中文的选区会列出本次待发送的正文、段数和字符数。勾选同意并点击生成后才发送。修改原文、范围或模式会清除这次同意。

## 在线快读与数据处理

浏览器逐段将选中的中文或中英混合正文直接发送给 MyMemory，收到英文后在本机按角色朗读。请求不另附昵称、时间或 ZIP 附件，正文中提到的个人信息也会随句发送。MyMemory 可能长期保存提交的片段并交给翻译合作方处理。使用者可以在每次发送前预览，或选纯本机翻译。[MyMemory 服务条款](https://mymemory.translated.net/terms-and-conditions)

匿名接口有每日额度，遇到限流会提示并保留原文。网站只调用翻译查询接口，不向译文库主动贡献聊天。[MyMemory 使用限制](https://mymemory.translated.net/doc/usagelimits.php)

同一选区如果有个别原句没有取得可用英文，页面会按句序列出原文并保留成功的译文。可手动补英文、经再次同意后只重试待译片段，或明确选择仅用已译句生成节选卡。生成在线卡后，「校对英文」可以按上下文修正任何一句，再用修改后的台词朗读或配音。补写的内容仅在本页处理，切换选区或刷新前请先保存制成的卡片。

## 在线自然双人配音

生成在线快读卡后，展开「自然双人配音」。第一位发言人默认使用 Kokoro 的 Heart 女声，第二位使用 Michael 男声。多人对话依次复用这两种音色。可以逐人调整，也可以交换男女声。首页的饼干对话用的是这组音色，可直接试听。

在卡片上核对待发送的英文台词，单独勾选本次配音后，浏览器才将这些台词和音色发给 TTS.ai。发送内容不另附昵称、时间和附件。台词中提到的人名也会随句发送。服务方暂存音频并记录 IP 等使用信息。免费生成的录音限个人非商业使用。[隐私政策](https://tts.ai/privacy/) · [服务条款](https://tts.ai/terms/)

匿名接口有用量和频率限制。生成时显示当前句数，可停止。在同一张卡上重试会复用已收到的录音。录音齐全后可按句播放、存入练习库，或导出带字幕的离线文件。[配音接口说明](https://tts.ai/api/)

## 听和复习

可以切换上一句、下一句，打开「单句循环」，按需调速、隐藏原文。生成后可为卡片起名，点「存入我的练习」保存字幕和配音，或保存轻量模式的系统声音选择。在同一设备和浏览器中可以从上次听到的句子继续。离线页面缓存就绪后也可打开已保存的练习。清理网站数据会移除练习，重要的 Kokoro 卡可另行导出。

## 导入微信对话

可以直接粘贴“昵称：消息”，也可以把微信中复制的“昵称、日期时间、正文”多行记录整段粘贴。用手机保存过微信导出包时，点“导入微信 ZIP”选择文件即可。压缩包在设备上打开，取出聊天文字；图片、语音等附件不参与翻译。

## 纯本机制作

选择 Kokoro 可在设备上生成实际音频，可保存带字幕的跟读文件。第一次处理含中文的对话，翻译和语音模型合计约 250 MB。

也可以选择轻量朗读，使用系统报告为本地的英语声音，边听边看同一份字幕。它只实时朗读，可用的音色取决于设备。新设备首次翻译中文仍需下载约 130 MB；纯英文材料可跳过翻译模型。

两种纯本机模式均不发送聊天给在线翻译服务。「提前下载并检查」可以先准备模型。主要模型按分块校验并缓存，设备存储可用时中断后可复用。iOS 可能挂起后台网页。

## 自行运行

把此目录放到任意支持 HTTPS 的静态托管服务即可。也可以在电脑上进入此目录，运行以下命令，再打开 http://127.0.0.1:8080/ 。

    python3 -m http.server 8080 --bind 127.0.0.1

iPhone 可在 Safari 中打开已部署的 HTTPS 网址，使用分享菜单中的“添加到主屏幕”。网址支持子目录部署。

## 配音与翻译

Kokoro 82M 负责英语配音，Marian 中文到英文模型负责翻译。只有选择纯本机模式才会下载相应模型。模型和运行组件由本站按需提供。缓存暂时无响应时自动绕过，网络读取停滞时会重试。文件来源与固定版本见 [资源清单](./assets/manifest.json)。
