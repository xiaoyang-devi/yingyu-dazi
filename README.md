# 英语搭子

粘贴一句话、一段文字或带昵称的微信聊天，也可以从设备选择微信导出的 ZIP 聊天记录，在浏览器中得到英语朗读和逐句滚动的双语字幕。可点一句重听、调速、隐藏原文，也可将用 Kokoro 配音的听力卡保存成可离线播放的 HTML 文件。

导入聊天后，点击「同意并生成自然配音」即可制作一张听力卡。网站会翻译需要翻译的句子，然后用 Heart 女声和 Michael 男声为不同角色配音。纯英文直接配音。在线制作无需下载模型。首页可以先试听一段六句的虚构对话。

## 在线制作与数据处理

生成按钮旁会说明本次发送范围和各服务的用途。每次点击只同意本次制作。浏览器逐段将选中的中文或中英混合正文发送给 MyMemory，将英文台词和音色发送给 TTS.ai。请求不另附昵称、时间或 ZIP 附件，正文中提到的个人信息会随句发送。MyMemory 可能长期保存提交的片段并交给翻译合作方处理。使用者可以先查看选中的原文，也可选择纯本机制作。[MyMemory 服务条款](https://mymemory.translated.net/terms-and-conditions)

MyMemory 匿名查询每天限 5,000 字符。网站只调用翻译查询接口。[MyMemory 使用限制](https://mymemory.translated.net/doc/usagelimits.php)

可以单独开启「MyMemory 额度用完时，允许 OPUS Translate 接着翻译」。此偏好记在当前浏览器。MyMemory 明确回报免费额度已用完时，网站会等待已发出的请求完成，再把仍需接译的正文逐段发给 Hugging Face 上由 Helsinki-NLP 提供的 OPUS Translate。服务在云端生成英文，未声明原句的保留时间，也可能排队或限流。普通网络故障会保留进度供重试。已译片段在同一页面、同一选区内可以复用。[备用翻译服务](https://huggingface.co/spaces/Helsinki-NLP/opus-translate)

如果个别原句没有取得可用英文，页面会保留成功的译文。可手动补英文、只重试待译片段，或明确选择仅用已译句制作节选。使用「校对英文」可以按上下文修正台词。单独发出的问号默认读作 “Huh?”，其他纯符号或表情可以补写口语表达。

## 在线自然双人配音

默认按出场次序分配 Kokoro 音色，第一位发言人用 Heart，第二位用 Michael。多人对话会复用这两种声音，制作前可在「角色与声音」里调整每个人的音色。

TTS.ai 暂存音频并记录 IP 等使用信息。免费生成的录音限个人非商业使用。[隐私政策](https://tts.ai/privacy/) · [服务条款](https://tts.ai/terms/)

网站直接调用 TTS.ai 的匿名免费接口。在线生成不占用 ChatGPT 或 OpenAI API 额度，TTS.ai 按公网 IP 限制每日字符数和请求频率。在同一张卡上重试会复用已收到的录音。生成好的录音可按句播放，整卡完成后可存入练习库或导出带字幕的离线文件，重听已保存的录音无需再次生成。[配音接口说明](https://tts.ai/api/)

在线配音同时处理最多两条主服务任务，按原文顺序呈现字幕。生成一句后就能先播放，听到尚未生成的句子时会等待并接续。点击暂停会停止自动接续。免费主服务每分钟最多接受十条配音请求；开启备用后，到达这一上限或主服务拒绝新任务并返回短时限流时，本次剩余部分会转到备用服务，无需等主服务的下一分钟。主服务已经接受的任务会先完成，不会重复提交。未开启备用时，本机预检到频率上限仍会等待并显示预计时间。发生错误或停止生成后，重试会复用本页已接受的任务和完成的录音。完整生成后可保存和导出。

想在主服务配音额度不足或生成限速时继续，可以在生成按钮上方开启备用配音。当前浏览器会记住这个选择，可随时关闭。已经生成的句子和长句中已完成的分段会保留，只给剩余部分配音。本次切换后持续使用备用，避免反复切换；同一选区内重试时会遵守主服务冷却时间。备用服务由 kinabraytan 维护，运行在 Hugging Face Spaces 上，使用 Bella 女声和 Michael 男声。若切换发生在长句中，女声会从 Heart 变为 Bella，卡片会标明含备用配音。它会收到需要新配音的英文和音色，生成可通过链接访问的临时录音。服务未注明音频保留时间，也可能排队、限流或暂不可用，因此不能保证所有网络条件下连续播放。备用配音和备用翻译分别授权。[备用服务说明](https://huggingface.co/spaces/kinabraytan/kokoro-tts-server/blob/main/README.md)

## 听和复习

可以切换上一句、下一句，打开「单句循环」，按需调速、隐藏原文。生成后可为卡片起名，点「存入我的练习」保存字幕和配音。在同一设备和浏览器中可以从上次听到的句子继续。离线页面缓存就绪后也可打开已保存的练习。清理网站数据会移除练习，重要的录音卡可另行导出。

## 导入微信对话

单条无昵称的文字默认使用「朗读」这个角色，可以选择女声或男声。普通多行文字会作为同一个人的正文。若正文里的冒号被识别成昵称，可勾选「作为一条消息朗读」以保留整段文字。

多人聊天可以直接粘贴“昵称：消息”，也可以把微信中复制的“昵称、日期时间、正文”多行记录整段粘贴。用手机保存过微信导出包时，点“导入微信 ZIP”选择文件即可。压缩包在设备上打开，取出聊天文字，图片、语音等附件不参与翻译。

## 纯本机制作

选择 Kokoro 可在设备上生成实际音频，可保存带字幕的跟读文件。第一次处理含中文的对话，翻译和语音模型合计约 250 MB。

纯本机制作将聊天留在设备上，纯英文材料可跳过翻译模型。「提前下载并检查」可以先准备模型。主要模型按分块校验并缓存，设备存储可用时中断后可复用。iOS 可能挂起后台网页。

## 自行运行

把此目录放到任意支持 HTTPS 的静态托管服务即可。也可以在电脑上进入此目录，运行以下命令，再打开 http://127.0.0.1:8080/ 。

    python3 -m http.server 8080 --bind 127.0.0.1

iPhone 可在 Safari 中打开已部署的 HTTPS 网址，使用分享菜单中的“添加到主屏幕”。网址支持子目录部署。

## 配音与翻译

Kokoro 82M 负责英语配音，Marian 中文到英文模型负责翻译。只有选择纯本机模式才会下载相应模型。模型和运行组件由本站按需提供。缓存暂时无响应时自动绕过，网络读取停滞时会重试。文件来源与固定版本见 [资源清单](./assets/manifest.json)。
