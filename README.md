# 英语搭子

粘贴带昵称的微信文字，或从设备选择微信导出的 ZIP 聊天记录，在浏览器中得到分角色英语朗读和逐句滚动的双语字幕。可点一句重听、调速、隐藏原文，也可将用 Kokoro 配音的听力卡保存成可离线播放的 HTML 文件。

导入聊天后，点击「同意并生成自然配音」即可制作一张听力卡。网站会翻译需要翻译的句子，然后用 Heart 女声和 Michael 男声为不同角色配音。纯英文直接配音。在线制作无需下载模型。首页可以先试听一段六句的虚构对话。

## 在线制作与数据处理

生成按钮旁会说明本次发送范围和两个服务的用途。每次点击只同意本次制作。浏览器逐段将选中的中文或中英混合正文发送给 MyMemory，将英文台词和音色发送给 TTS.ai。请求不另附昵称、时间或 ZIP 附件，正文中提到的个人信息会随句发送。MyMemory 可能长期保存提交的片段并交给翻译合作方处理。使用者可以先查看选中的原文，也可选择纯本机制作。[MyMemory 服务条款](https://mymemory.translated.net/terms-and-conditions)

匿名接口有每日额度，遇到限流会提示并保留原文。网站只调用翻译查询接口，不向译文库主动贡献聊天。[MyMemory 使用限制](https://mymemory.translated.net/doc/usagelimits.php)

如果个别原句没有取得可用英文，页面会保留成功的译文。可手动补英文、只重试待译片段，或明确选择仅用已译句制作节选。使用「校对英文」可以按上下文修正台词。单独发出的问号默认读作 “Huh?”，其他纯符号或表情可以补写口语表达。

## 在线自然双人配音

默认按出场次序分配 Kokoro 音色，第一位发言人用 Heart，第二位用 Michael。多人对话会复用这两种声音，制作前可在「角色与声音」里调整每个人的音色。

TTS.ai 暂存音频并记录 IP 等使用信息。免费生成的录音限个人非商业使用。[隐私政策](https://tts.ai/privacy/) · [服务条款](https://tts.ai/terms/)

网站直接调用 TTS.ai 的匿名免费接口。在线生成不占用 ChatGPT 或 OpenAI API 额度，TTS.ai 按公网 IP 限制每日字符数和请求频率。在同一张卡上重试会复用已收到的录音。录音齐全后可按句播放、存入练习库，或导出带字幕的离线文件，重听已保存的录音无需再次生成。[配音接口说明](https://tts.ai/api/)

## 听和复习

可以切换上一句、下一句，打开「单句循环」，按需调速、隐藏原文。生成后可为卡片起名，点「存入我的练习」保存字幕和配音。在同一设备和浏览器中可以从上次听到的句子继续。离线页面缓存就绪后也可打开已保存的练习。清理网站数据会移除练习，重要的录音卡可另行导出。

## 导入微信对话

可以直接粘贴“昵称：消息”，也可以把微信中复制的“昵称、日期时间、正文”多行记录整段粘贴。用手机保存过微信导出包时，点“导入微信 ZIP”选择文件即可。压缩包在设备上打开，取出聊天文字；图片、语音等附件不参与翻译。

## 纯本机制作

选择 Kokoro 可在设备上生成实际音频，可保存带字幕的跟读文件。第一次处理含中文的对话，翻译和语音模型合计约 250 MB。

纯本机制作将聊天留在设备上，纯英文材料可跳过翻译模型。「提前下载并检查」可以先准备模型。主要模型按分块校验并缓存，设备存储可用时中断后可复用。iOS 可能挂起后台网页。

## 自行运行

把此目录放到任意支持 HTTPS 的静态托管服务即可。也可以在电脑上进入此目录，运行以下命令，再打开 http://127.0.0.1:8080/ 。

    python3 -m http.server 8080 --bind 127.0.0.1

iPhone 可在 Safari 中打开已部署的 HTTPS 网址，使用分享菜单中的“添加到主屏幕”。网址支持子目录部署。

## 配音与翻译

Kokoro 82M 负责英语配音，Marian 中文到英文模型负责翻译。只有选择纯本机模式才会下载相应模型。模型和运行组件由本站按需提供。缓存暂时无响应时自动绕过，网络读取停滞时会重试。文件来源与固定版本见 [资源清单](./assets/manifest.json)。
