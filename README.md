# 英语搭子

粘贴带昵称的微信文字，或从设备选择微信导出的 ZIP 聊天记录，在浏览器中得到分角色英语朗读和逐句滚动的双语字幕。可点一句重听、调速、隐藏原文，也可将用 Kokoro 配音的听力卡保存成可离线播放的 HTML 文件。

打开网站可直接听六句虚构示例。第一次生成新对话需要联网下载模型，建议使用 Wi-Fi 并保持页面打开。支持 WebAssembly SIMD 的现代浏览器可运行本地模型。浏览器存储清理后可能需要重新下载。网页不采集聊天内容，不提供云端聊天历史。处理质量受原文、翻译模型和可用内存影响。

生成时，翻译和配音分别显示模型文件的读取进度及已处理句数。引擎初始化没有可测百分比；在前台等了一段时间仍无新进度时，可以继续等，也可以点“重新尝试”，无需再导入聊天。切到后台的时间不会触发超时报错。若浏览器关闭或重新载入整个页面，仍需重新导入。

## 导入微信对话

可以直接粘贴“昵称：消息”，也可以把微信中复制的“昵称、日期时间、正文”多行记录整段粘贴。用手机保存过微信导出包时，点“导入微信 ZIP”选择文件即可。压缩包在设备上打开，取出聊天文字；图片、语音等附件不参与翻译。

## 两种朗读方式

默认的 Kokoro 在设备上生成实际音频，可保存带字幕的跟读文件。第一次处理含中文的对话，翻译和语音模型合计约 250 MB。

也可以选择轻量朗读，使用系统报告为本地的英语声音，边听边看同一份字幕。它只实时朗读，可用的音色取决于设备。新设备首次翻译中文仍需下载约 130 MB；纯英文材料可跳过翻译模型。

## 自行运行

把此目录放到任意支持 HTTPS 的静态托管服务即可。也可以在电脑上进入此目录，运行以下命令，再打开 http://127.0.0.1:8080/ 。

    python3 -m http.server 8080 --bind 127.0.0.1

iPhone 可在 Safari 中打开已部署的 HTTPS 网址，使用分享菜单中的“添加到主屏幕”。网址支持子目录部署。

## 配音与翻译

Kokoro 82M 负责英语配音，Marian 中文到英文模型负责翻译。输入中文及生成的英语、音频在浏览器中处理。模型与运行库从 Hugging Face、jsDelivr 下载。浏览器将像访问其他网站一样向托管和下载服务发送获取文件所需的网络请求。
